# TabListLimiter

TabListLimiter is a Minecraft plugin designed to limit the number of players visible on the tab list to a maximum of 10. It ensures that no player on the server can see all online players in the list. Server operators (OPs) will always appear at the top of the 10-player list, with the remaining spots filled by randomly selected non-operator players.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Paper 1.21.11 server.
3. Restart or reload your server to enable the plugin.

## Use

1. Once the server is running with the plugin installed, players will automatically see a limited tab list.
2. Operators will always appear at the top of the list, followed by randomly selected non-operators to fill the remaining spots.
3. To reload the plugin configuration, use the command `/reloadconfig` (requires OP permissions).
